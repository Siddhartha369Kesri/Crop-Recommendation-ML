Trained Machine Learning Models:

This folder contains the trained Machine Learning model used in the Crop Recommendation System.

Model File:
"best_crop_model.pkl"

Model Selection:
Three Machine Learning algorithms were trained and evaluated:

1. Decision Tree Classifier
2. Random Forest Classifier
3. Support Vector Machine (SVM)
The best-performing model was selected based on test accuracy.

Purpose:
The saved model is used to predict suitable crops based on user-provided soil and environmental parameters.
