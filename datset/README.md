Dataset

This folder contains the dataset used for the Crop Recommendation System.

Dataset Name: Crop Recommendation Dataset

Source: Kaggle

The dataset contains 2,200 records and 8 columns, including soil nutrients, environmental conditions, and crop labels.

Features:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

Target Variable: "label"
