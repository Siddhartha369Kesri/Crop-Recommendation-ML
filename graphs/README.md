Data Visualizations:

This folder contains graphical visualizations generated during the Crop Recommendation Machine Learning project.

Graphs Included:

1. "confusion_matrix.png" – Displays the actual and predicted crop classifications.
2. "model_accuracy_comparison.png" – Compares the accuracy of Decision Tree, Random Forest, and Support Vector Machine models.

Purpose:
These visualizations help understand model performance and compare the results of different Machine Learning algorithms.
